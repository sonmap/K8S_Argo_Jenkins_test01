Kubernetes CI/CD Demo Portal

GitHub → Jenkins → Docker Build → Local Registry → GitOps → Argo CD → Kubernetes

현재 Nginx 컨테이너 이미지에는 메인, Frontend, Backend/Admin 예제 HTML이 함께 포함됩니다.
