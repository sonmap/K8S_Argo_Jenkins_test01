FULL STACK DEMO

Kubernetes Frontend + Backend + MySQL

GitHub 소스를 Jenkins가 두 개의 Docker Image로 빌드하고, Argo CD가 Frontend / Backend / MySQL 리소스를 Kubernetes에 배포하는 실습입니다.

GitHub → Jenkins → Docker Build → Local Registry → GitOps → Argo CD → Kubernetes
Browser → Nginx Frontend → Spring Boot Backend → MySQL

1. Frontend

demo-web / Nginx

HTML 화면과 고객 조회 UI를 제공하며 /api 요청을 Backend Service로 Proxy합니다.

고객 조회 화면

2. Backend

demo-backend / Spring Boot

REST API로 요청을 받고 JDBC를 사용해 MySQL의 customers 테이블을 조회합니다.

Backend 상태 화면

3. Database

demo-mysql / MySQL 8.4

샘플 고객 5건을 초기 데이터로 생성하고 Backend에서 ClusterIP로 접근합니다.
